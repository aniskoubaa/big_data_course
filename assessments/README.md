# Assessments

Course assessments for SE 446: Big Data Engineering.

## Assessment Overview

| Assessment | Weight | Format | Timing |
|-----------|--------|--------|--------|
| Midterm 1 | 20% | Written (in-class, 90 min) | Week 6 |
| Midterm 2 | 20% | Written (in-class, 90 min) | Week 10 |
| Final Exam | 30% | Written (comprehensive, 120 min) | Finals period |
| Quiz 1 | 5% | Moodle MCQ (25 min) | Week 4 |
| Quiz 2 | 5% | Moodle MCQ (25 min) | Week 8 |
| Project Milestones | 20% | M1-M5, 4% each | Weeks 4-12 |

## Midterm Coverage

| Exam | Topics Covered | Key Skills Tested |
|------|----------------|-------------------|
| Midterm 1 | HDFS, MapReduce, Hive, YARN | Architecture, CLI commands, HiveQL queries, YARN resource model |
| Midterm 2 | Spark (Core, Tuning, MLlib) | RDD/DataFrame API, caching, pipelines, model evaluation |

## Quiz Format

- 10 questions per quiz (5 MCQ + 5 short answer/numerical)
- Generated with ExamGPT and exported to Moodle XML
- Weekly in-class quizzes are in `lectures/weekXX/quizzes/`

## Folder Structure

```
assessments/

├── midterms/
│   ├── midterm1/      # Midterm 1 materials

├── final/             # Final exam materials

    └── quiz2/         # Quiz 2 (Week 8)
```

## Note

Assessment content (questions, solutions) is kept private and excluded from the public repository via `.gitignore`.
